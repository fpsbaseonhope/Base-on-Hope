Site Content Editor

Edit founders and project article content, then commit the changes directly to the main branch. Your GitHub token is kept only in this browser tab and is never written into the website files.

1. Connect to GitHub

Use a GitHub fine-grained personal access token with access to this repository's Contents: Read and write permission. Do not paste the token into your source code.

2. Founders / Members

These cards are stored in index.html. You can edit names, roles, descriptions, and image paths.

3. Project Articles

These are the main project articles stored in projects.html. This editor changes the article title, status/tag, and main description in all three languages.

4. Publish

Nothing is published until you click the button below. The editor will commit the updated index.html and projects.html to main.
